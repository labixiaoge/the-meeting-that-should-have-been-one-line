One single sentence that could have replaced an entire pointless meeting — the decision, the deadline, and the real reason the meeting exists. The program writes the line to `/output/entry.txt`.

> The decision is already made, the deadline is Friday, and this meeting only exists because nobody wanted to be the one to send the email.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript natively). Writes `/output/entry.txt` (override with `OUTPUT_DIR`).
